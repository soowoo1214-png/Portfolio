# HSJ 포트폴리오 · GitHub 업로드용

## 실행
압축을 모두 풀고 VS Code에서 이 폴더를 여세요. index.html을 브라우저로 직접 열 수 있습니다. Node.js가 있다면 터미널에서 `node preview.cjs` 실행 후 표시되는 로컬 주소를 엽니다.

## 수정하는 파일
- `data/projects.js`: 작품 순서·제목·태그·미디어 경로·연락처·HOME 영상 목록
- `index.html`: HOME / WORKS / CONTACT 구성
- `css/style.css`: 밝은 배경, 색상, 반응형 배치
- `js/main.js`: 분류 필터, 12/9/6개 초기 표시, 스크롤 추가, 연락처
- `js/gallery.js`: 이미지 팝업·원본 크기·드래그
- `js/detail.js`: 실제 화면비의 영상/디자인 상세
- `js/hero.js`: 표지 영상 순환
- `js/common.js`: 공통 아이콘·링크·문자 처리

## 작품과 파일
`MY-PORTFOLIO-FILES`에는 실제로 사용하는 파일만 있습니다. 현재 작품은 비디오 7개 / AI 6개 / 디자인 7개 / 팀 프로젝트 4개입니다. 배열 위에 있는 작품부터 표시합니다. 분류별 사용자 지정 순서를 유지하며, ALL은 비디오 → AI → 디자인 → 팀 프로젝트 순서입니다. 실제 날짜는 추정하지 않았습니다.

파일 이름과 경로를 변경하면 data/projects.js에서도 함께 바꿔야 합니다. 파일만 넣어서는 카드가 등록되지 않습니다. 영상 교체 시 해당 항목의 width/height를 새 영상의 실제 크기로 수정하세요. 재생 전부터 공간을 확보하는 값입니다.

## 스크롤 동작
- 992px 이상: 처음 12개
- 576~991px: 처음 9개
- 575px 이하: 처음 6개
목록 끝에 도달하면 같은 수만큼 추가합니다. '작업 더 보기' 버튼은 키보드 및 자동 추가가 지원되지 않는 환경의 대체 수단입니다. 분류를 바꾸면 새 분류의 첫 묶음부터 표시합니다. 마지막 작품 뒤에는 CONTACT가 나옵니다.

## 영상 상세
썸네일 poster를 사용하지 않습니다. 처음부터 영상의 원본 비율로 표시하고 화면에 맞게 축소합니다. 카드 클릭 후 무음 자동 재생을 시도합니다. 브라우저 정책에 따라 막히면 기본 재생 버튼으로 시작합니다. 소리는 영상 컨트롤에서 켤 수 있습니다.
