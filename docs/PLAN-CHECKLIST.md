## 실제 자료가 필요한 항목

- 배경 몽타주: 실제 작품 파일 미제공. 현재 20초 예시 도식 영상으로 기능 구현. 실제 작품의 18~24초 하이라이트로 교체해야 합니다.
- 작품: PDF에서 확인되는 이름과 분류를 사용하되 이미지는 모두 자체 제작 교체용 도식입니다. 임의 브랜드명/작품명은 제거했습니다.
- 실제 역할: PDF에 적힌 동백커피 직접 촬영, 동래읍성축제 직접 촬영·모션그래픽만 출처를 표시해 사용했습니다. 나머지는 입력란입니다.
- 상세 설명·제작 연도·최종 소개·연락처·외부 링크: 확정 자료 미제공. 임의 사실을 만들지 않았습니다.
- 폰트: PDF의 제안 글꼴을 CSS 우선순위로 지정, 배포 파일 미포함. 시스템 산세리프 대체.
- PDF p13의 고해상도 최종 시안은 별도 제공되지 않았습니다. 수정본은 제공된 와이어프레임/확정 사양에 맞춘 구현이며 고해상도 시안을 재현했다고 주장하지 않습니다.
